# Wii Menu assets

Prepared by `docs/themes/wii-menu/reference/extract-assets.py` and `build-fonts.sh`.

| Directory | Source |
| --- | --- |
| `menu/`, `channels/`, `home/`, `options/`, `sd/`, `mail/` | [WM4K](https://github.com/Alan-bur/WM4K) at `b04bd27` by Alan Burcet, resampled to the size the System Menu loads; the clock digits, mail icon and Nintendo Channel name tinted as the console draws them |
| `settings/` | WM4K's whole-page Settings textures, one per state, as lossless WebP |
| `fonts/` | [M PLUS 1p](https://github.com/google/fonts/tree/main/ofl/mplus1p) by The M+ Project Authors, SIL Open Font License 1.1 (`fonts/OFL.txt`), cut to Latin |

WM4K has no licence file. Its README credits SuperDuperRob's 2019 "HD Wii Texture Pack", which it
continues with his permission, and its disclaimer says every texture is drawn by hand. These
textures are here with the repository owner's approval and are credited to the pack's author; they
are not covered by this repository's own licence.

The textures redraw the Nintendo Wii's System Menu. Nintendo, Wii and the channel names are
Nintendo's trademarks.
