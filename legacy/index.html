CFW UI mockups

HTML mockups of SBC gaming handheld firmware and launcher screens. Each screen renders at its device's exact resolution inside a device frame. See CLAUDE.md for how these are built.

PlayStation X

PlayStation-styled theme for the Batocera EmulationStation fork, reproducing the PS3, PS4 and PS5 interfaces. Interactive build carries all 11 screens, both colorsets with nine accents, three carousel styles, and the theme's 385 storyboard animations ported as data rather than hand-written CSS.

  • Theme (interactive) - Trimui Smart Pro (1280x720)
  • Theme (interactive) - RG552 (1920x1152)
  • Theme (interactive) - RG35XX (640x480, tinyScreen)
  • Theme (interactive) - RG34XX (720x480, tinyScreen)
  • System 1280 PS4 1280 PS5 1280 Detailed 1280 Grid 1280 Carousel 1280 Full grid 1280 Single 1280 Media 1280 Splash 1280 Launch 1280

Every screen also exists at 640x480, 720x480 and 1920x1152 - see docs/themes/playstation-x.md.

Elementerial

EmulationStation theme built around Android TV's interface with the elementary OS palette. Interactive build carries all eight views, 14 colour schemes in dark and light, every theme subset, and the transitions read from EmulationStation itself.

Vitro Launcher
